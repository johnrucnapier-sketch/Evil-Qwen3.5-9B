# 证据、来源与发布检查

## 目录

- `data/cases.json`：最终64题及题型/生成预算；`cases-native.json`含模板和固定输入token IDs。
- `data/calibration.json`：32训练/8开发话题；这些是合成日常问题，不是生产聊天或私有教练知识库。
- `data/answers.json`：8条件×64题，保留完整可见回答、token IDs、截断与当时耗时。
- `evidence/personality/`：4B复现、9B梯度排名、两档筛选、主验证、细剂量探索、错误自动标签及纠正记录。
- `evidence/evo-quant/`：修正padding后的向量/随机/基线对照、HF桥接、引擎对照、向量因果检查。
- `evidence/evo-fit/`：拟合参数、开发选择、完整性检查、最终全部输出、判读、量化元数据。
- `research/`：当时研究脚本快照。仅泛化私人用户名路径与设备UUID，保留历史布局与已知缺陷供审计。
- `scripts/`：本次公开整理的环境变量化入口及CPU发布检查。不是已经重新GPU验收的实现。
- `models/`：五个HF发布模型卡、许可证、分发文件校验和、历史发布验证与新可见性检查。
- `provenance.json`：源研究提交、源相对文件名及源SHA256。`SHA256SUMS`对应当前公开包，两个哈希用途不同。

源研究基于2026-10-27固定提交 `83a5ecbc966939c1e83458c3d7ad2258fb2ab294`，另由 `provenance.json:1`逐文件标记来源。原始内部仓库不随本项目公开；独立新Git历史避免携带私有运维资料。早期报告中的内部相对路径/行号是历史溯源标识，不保证可从本仓直接点击，当前导航以上述公开路径为准。

## 历史时间边界

证据报告保留实验当时“未发布”“未上传”的原文，它们是阶段快照。最终状态以README固定HF发布表和models发布证据为准；独立格式已经发布。早期运行时向量候选不等于后来的独立模型。原研究报告末尾的服务恢复叙述不构成本仓的部署教程或未来停服授权。

最终问答评阅来自知晓条件的助手，不是用户逐条人工验收。自动标签失败、掩码错误、原版也答错的题、能力损伤、截断和未完成项目均保留。没有训练答案蒸馏，没有证明能力无损，没有证明移除安全拒绝。

## 公开范围和许可

自编PyTorch研究代码及合成题集/输出随Apache-2.0公开；模型保留上游Apache-2.0和修改声明。未复制第三方gist代码、模型权重、pile-10k原始语料或第三方依赖源码。它们的来源和各自许可独立适用；校准配方仅引用公开数据集名称。没有新增模型使用限制。见 [../LICENSE:1](../LICENSE#L1)、[../NOTICE:1](../NOTICE#L1)、[../research/evo_fit_20261027/quantize.py:1](../research/evo_fit_20261027/quantize.py#L1)。

发布前检查包括凭据格式、私有地址/用户名路径、邮箱、SSH材料和文件类型；未包含环境文件、上传代理、私有网络清单、访问令牌、聊天转录或模型二进制。检查工具是有限的静态检查，不代表第三方安全审计。文件哈希和CPU数据一致性可以本地重跑；本次整理未重跑GPU搜索、拟合或量化。
